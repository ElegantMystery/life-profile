# Connect your existing assistant

This is your private instance, separate from the public template. No personal claims have been supplied. Local plaintext files are not encrypted. A cloud-backed assistant may send any content you provide or let it read to its provider. Check that assistant's data handling before continuing. This project makes no model calls itself.

## First session

1. Open this private folder in your existing coding assistant, or explicitly grant access to the specific files you want it to use. Do not open your whole home directory or public template repository as a substitute.
2. Paste this session-start request, replacing the folder placeholder with your private folder:

```text
Read <private-folder>/ASSISTANT-GUIDE.md and follow its basic setup flow.
Read SETUP-PROGRESS.md for continuity. Do not scan other files or accounts.
Ask which profile files are relevant before reading additional private content.
Start with a few basics, or offer a draft from context I explicitly select.
Show proposals and obtain my confirmation before saving structured records.
Do not export, upload, change agent configuration or act on my behalf.
```

3. Have the assistant identify the loaded guide path and summarize the boundaries. If it cannot access the folder, stop; do not paste the whole private instance into a public project. You may explicitly share only the guide's generic text and selected answers, understanding the provider's processing.
4. Point the assistant to the local Life Profile tools checkout if you want it to validate drafts or confirm selected records. Tools are not copied here. Keep command paths explicit.

## Later sessions

Paste the same request and name the task or module you want to resume. This guide is not automatically loaded by every assistant. If your tool supports project-scoped instructions, you may manually add a reference to this guide in a private workspace configuration; review the file and access scope first. Do not put a private path or profile text in a shared repository, and do not edit global configuration merely to connect this instance.

The guide and progress files remain useful when changing assistants. No subscription, server, API key or particular AI vendor is required by Life Profile. Markdown instructions cannot enforce agent behavior or restrict filesystem access.
