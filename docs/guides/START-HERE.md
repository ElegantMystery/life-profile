# Continue with your agent

Your private instance contains data, not instructions. Open the selected template or fork and configure the agent using [instruction sources](../INSTRUCTION-SOURCE.md). The host needs both the verified instruction repository/version and the separate data destination; opening only the private folder does not load this guide.

For setup, follow [AI setup](../AI-SETUP.md). For ordinary conversations, use the [shared assistant guide](ASSISTANT-GUIDE.md) and its activation checklist. A fresh session test is needed before claiming persistent loading; session-only or pending activation is valid. Data initialization is not complete onboarding.

Keep sensitive facts and secrets out of the profile. You can skip, correct or say “do not save.” Files are plaintext and a cloud-backed assistant may process what it reads. Local updates do not authorize uploads; direct GitHub saves need explicit authorization for the private repository and branch. See [privacy](../PRIVACY.md) and [storage](../STORAGE.md).

Existing profiles remain in place without reinitialization. A template update does not replace old copied instructions. Customize behavior in a selected fork and use the [reviewed migration](../MIGRATIONS.md#centralized-instructions-and-data-only-instances) before switching an existing profile to centralized guidance. A fork needs deliberate upstream updates and must not expose private information.
